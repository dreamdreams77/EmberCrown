# Ember art: visual vertical slice (Ashfall Keep)

A playable prototype of a new art direction for EmberCrown. The gameplay is the current pixel-art game, unchanged. What changed is the
art: original, purpose-drawn characters with real faces, a redesigned Marrow room, and one UI language from title screen to HUD.
Branch `feature/ember-art-slice` (from `main` at `9f6b3f4`). Never merged; `main` is untouched. Pushed to origin up to `0833065` (round 2); the round-3 commits (`0ed15b2` phase 1, `81b1f94` phase 2, `8aded60` phase 3) are local only, awaiting permission to push.

**Try it:** open `EmberCrown-ember-slice.html` in this folder in any browser (desktop or phone). It is one self-contained file.
Ashfall Keep is the only mission drawn in the new art; the other missions, the Rookery hub and every NPC other than Shiloh and
Ashling keep the existing LPC art. The pause menu has an **Ember art** toggle that switches the whole slice back to the original look,
and the existing **HD-2D light** toggle still works (it now defaults to off, which is configuration B).

## What is new in the code
* Round 3 adds `screens.py` (title, briefing, victory, defeat illustrations), `phase2.py` (pickups, mechanisms, story props, arches, beams, markers, HUD icons), `plan.js` (furniture planner), `appear.js` (proves which sprites really draw in the mission), `closeups2.js`, `menus.js` captures; the game gets a documented `set:` list in `js/data.js` and small gated `window.EMX` hooks in `mis_a.js`, `tiles.js`, `hud.js`, `pixel.js`, `props.js`, `ui.js`. New tests: `tests/layout_ashfall.test.js`, `tests/ember_visible.test.js`, `tests/ember_screens.test.js`.
* Round 2 adds `set2.py`, `ruin.py`, `people2.py` (doors, chests, pots, braziers, rugs, floor details, wall shadows, ruined set, Pip and Hale) and the review tools `rooms.js`, `objects.js`, `gameplay.js`, `perf.js`, `fps.js`.
* `tools/ember_art/` the art pipeline: `pix.py` (painter: masks, one light, 5-tone ramps, selective outline), `biped.py` (shared chibi skeleton),
  `shiloh.py`, `guards.py`, `cinder.py`, `ashling.py`, `faces.py`, `tiles_ashfall.py`, `props_ashfall.py`, `build_ember.py` (writes `assets/ember/`),
  plus the capture, sheet and bundle scripts. No source images are read: every pixel comes from these painters and hand-placed stamps.
* `assets/ember/` generated sheets and `meta.js`. `js/ember.js` wraps the draw functions (same pattern as `js/lpc.js`); `ember.css` is the UI skin.
* Small edits to existing files: `index.html` (load the new files), `js/game.js` (defaults: `ember:true`, `hd2d:false`), `js/ui.js` (the toggle),
  `js/render.js` (a softer fire light while Ember art is on). `tests/ember.test.js` is new; the full suite passes (33 suites plus the syntax check at the round-3 head).
* Nothing in `assets/lpc/` was touched or replaced.
